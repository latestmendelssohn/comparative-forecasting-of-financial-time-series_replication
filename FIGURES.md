# Generated figures

The R script creates the exploratory plots, residual diagnostic plots, model-forecast plots, variable-importance plots, and GARCH conditional-volatility plots in the working directory. Run `nifty50_complete_analysis.R` from the repository root to generate them. The academic report references the four principal actual-versus-predicted plots by filename.

The PNG plots are not committed in this initial bundle because the underlying saved R forecast vectors and data vintage were not available in the current workspace to regenerate those exact charts. Run the script to create them from Yahoo Finance data.
